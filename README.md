# Vocode

自分でコードを書きながら、質問や実装依頼を声で伝えられるローカル開発アプリです。

## 起動

Node.js 20 以上が必要です。初回に依存パッケージをインストールします。

```bash
cp .env.example .env
# .env の OPENAI_API_KEY に自分の API キーを設定
npm install
npm start
```

ブラウザで **http://127.0.0.1:4173** を開きます。API キーがなくてもコード編集、ローカル保存、プレビューは使えます。AI への質問、実装依頼、音声の文字起こしには API キーが必要です。音声回答はブラウザの読み上げ機能を使用します。

画面上部のフォルダ名、または新規作成画面の「保存先フォルダを選ぶ…」から、このコンピュータ上の作業フォルダを選べます。macOS の標準フォルダ選択画面を使うか、既存フォルダの絶対パスを入力してください。選んだ場所が新しいファイルとフォルダの保存先になり、次回起動時にも使われます。フォルダを切り替えても、以前のフォルダの内容は移動しません。他の OS では絶対パス入力または `.env` の `VOCODE_WORKSPACE=/絶対パス/プロジェクト` を使えます。未選択なら同梱の `workspace/` を使用します。

## 使い方

- 左側でフォルダを展開し、ファイルを開きます。上部のボタンでファイルとフォルダを作成できます。各項目の `…` メニューまたは右クリックから名前変更・移動・ゴミ箱への移動ができます。フォルダへドラッグして移動することもできます。ゴミ箱の項目は復元できます。
- 中央の CodeMirror エディタでは、ファイルの言語に合わせてコードを色分けします。編集内容は約0.8秒後に選択中の作業フォルダへ自動保存します。`⌘/Ctrl + S` でも即時保存できます。タブの `×` で閉じられます。外部で同じファイルが変更された場合は保存時に競合を表示します。
- 画面右上の「ローカルに保存」から、別のフォルダへプロジェクトをコピーするか、ZIPとしてダウンロードできます。フォルダへのコピーは対応ブラウザで利用でき、同名ファイルを上書きする前に確認します。ZIPには空フォルダや画像などのバイナリファイルも含まれます。
- 「プレビュー」で HTML ページを確認できます。変更を保存してから更新してください。
- 右側の「質問する」は現在のコードについて回答します。「実装を頼む」はファイル変更案を作ります。内容を開いて確認し、「変更を適用する」で保存します。
- マイクボタンを押して話し、もう一度押すと文字起こしして送信します。初回はブラウザのマイク許可が必要です。
- `.env` の `OPENAI_MODEL` で AI モデルを変更できます。

このアプリは自分のコンピュータの `127.0.0.1` でのみ待ち受けます。選択したプロジェクトの外にあるファイルは編集できません。`.git`、`node_modules`、`.env` などは一覧、AI の読み込み、書き出しの対象から除外します。AI にはプロジェクト内のテキストファイルの内容が質問時に送信されます（合計最大約 70 KB）。秘密情報を編集対象のプロジェクトに置く場合は注意してください。

ファイル操作の確認には `npm test` を実行できます。
